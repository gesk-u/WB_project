# Sanahaku — Sprint 1 Documentation

This directory contains the Sprint 1 planning, product backlog, design artifacts, and team reflections for **Sanahaku**, a web platform built to help language learners hear natural, conversational Finnish pronunciation in timestamped YouTube videos.

---

## Sprint 1 Overview

**Sprint Goal:** Finalize the project idea, organize team roles and workflow, create low-fidelity UI/UX wireframes, and prototype core user stories.
**Team Members:**
  * **Anastasiia:** Scrum Master
  * **George:** Product Owner
  * **Veronika:** Lead UI/UX Designer
  * **Maria:** Frontend Development (CSS/Tailwind)

**Sprint Status:** Finished.

---

## Core Deliverables in this Directory

* **Project Description:** Detailed overview of Sanahaku, including target users, stakeholders, problem statement, product vision, and main functionality.
* **Product Backlog:** List of user stories (`US-01` through `US-07`) with acceptance criteria covering core search, UI themes, spellchecking, bookmarks, and AI features.
* **Sprint 1 Documentation:** Outline of the Sprint Goal, itemized task backlog assigned per team member, Definition of Done, role descriptions, and Scrum reflections.
* **Low-Fidelity Prototype:** Link to the interactive Figma UI wireframes and user journey prototype.
* **Presentation:** Link to the project presentation slide deck created in Figma Slides.
